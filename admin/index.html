Админка блога

Вход по токену GitHub — тому же, что для старой админки. Он хранится только в этом браузере.

Где взять токен?
  1. Откройте github.com → новый токен.
  2. Repository access → Only select repositories → blog-com.
  3. Permissions → Repositories → Contents: Read and write.
  4. Generate token, скопируйте и вставьте сюда.
